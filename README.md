# Data Science Assignment One

The objective of this assignment is to extract a dataset from a set of web pages and use Python to prepare, analyse, and derive insights from the collected data.

This project will be based on [Dublin Rental Property Database](http://mlg.ucd.ie/modules/python/sources/rental/index.html) from the list of [posibile links](http://mlg.ucd.ie/modules/python/sources) to choose from. 

#### The tasks involved in this project are:

| **Tasks** | **Component** | **Mark** |
|:-----------:|:---------------|:----------:|
| Task 1 | • Web scraping and parsing <br> • Saving data in an appropriate format | 30 |
| Task 2 | • Loading dataset in an appropriate representation <br> • Data pre-processing (cleaning, filtering, transformation) <br> • Explanation of steps | 25 |
|  | • Characterisation, summarisation, and analysis <br> • Use of visualisations and tables <br> • Explanation and interpretation of results | 25 |
| Task 3 | • Discuss challenges faced in collecting data <br> • Summarise key insights from analysis <br> • Suggest ideas for further work | 10 |
| General | • Python code quality and notebook structure <br> • Use of Markdown cells for interpretation and explanation | 10 |
|  | **Total** | **100** |
